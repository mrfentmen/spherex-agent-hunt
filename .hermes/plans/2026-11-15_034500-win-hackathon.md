## Goal

- FITS frames are about 62–69 MB each. Never commit FITS. Work in `/tmp`, delete FITS after runs.
- Deadline pressure: optimize for judge trust and a smooth 5-minute demo, not for new features.

```python
def pick_overlapping_frames(records, min_gap_days=1.0, max_sep_deg=0.5, limit=3):
    """Pick same-sky frames across spaced epochs."""
    from .detections import angular_sep_arcsec

    cands = [r for r in records if r.ra_deg is not None and r.dec_deg is not None and r.t_min_mjd is not None]
    cands.sort(key=lambda r: r.t_min_mjd)
    picks = []
    for r in cands:
        if not picks:
            picks.append(r)
            continue
        if len(picks) >= limit:
            break
        if r.t_min_mjd - picks[-1].t_min_mjd < min_gap_days:
            continue
        if angular_sep_arcsec(picks[0].ra_deg, picks[0].dec_deg, r.ra_deg, r.dec_deg) > max_sep_deg * 3600.0:
            continue
        picks.append(r)
    return picks
```

## Risks, tradeoffs, and open questions
- Linear TAN WCS can be arcminutes off near field edges; the 6-arcsec linker may still find zero real tracks. Keep zero honest; do not loosen gates to manufacture a discovery.
- Brightest-top-K peaks can select different stars per epoch. Overlap picking plus NMS/edge guards reduce this, but true cross-epoch association may need catalog matching or full SIP astrometry.
- Sandbox/venue proxies kill wide cones. Demo only 0.05 deg cones; keep CSV receipts as backup if live queries fail.
- Time is the main constraint. If rushed, do Tasks 1, 6, 7 first: verified receipts plus a flawless offline demo beat unfinished extractor tuning.
- Open: exact final live counts depend on the rerun; quote the Task 1/5 receipts, not older numbers. Open: whether judges value real-data honesty over a claimed candidate; this plan bets on honesty plus proof.
